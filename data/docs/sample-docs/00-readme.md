# Sample Documents

This folder is prepared for local viewer and editor testing.

## Covered flows

- Light preview: `md`, `txt`, `csv`, `json`, `yaml`, `ini`, `sql`
- PDF preview: `pdf`
- ONLYOFFICE: `docx`, `xlsx`, `pptx`

## Suggested test order

1. Open markdown and text files first.
2. Open csv/json/yaml/ini to check structured previews.
3. Open docx/xlsx/pptx to verify ONLYOFFICE view and edit flows.
4. Save an Office file and check whether index updates follow.
